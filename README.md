# Razo Games — الخطوة الأولى

هذه نسخة الخطوة الأولى من المشروع: تغيير الهوية إلى **Razo Games**، وتحديث الألوان إلى الأزرق الفاتح، مع الحفاظ على واجهة المكتبة الحالية.

## التشغيل محليًا
1. فك ضغط الملف.
2. افتح المجلد في VS Code.
3. افتح `index.html` في المتصفح، أو استخدم Live Server.

## مهم قبل الخطوة التالية
هذه النسخة **واجهة أمامية محلية فقط** وليست منصة عامة بعد:
- لا يوجد تسجيل دخول حقيقي حاليًا.
- الألعاب لا تُرفع إلى خادم ولا تظهر لمستخدمين آخرين.
- ملفات ZIP لا تبقى محفوظة بعد تحديث الصفحة؛ أعد إضافتها إذا اختفت.
- لا ترفع ألعابًا لا تملك حقوق توزيعها.

## الخطة التالية
1. إصلاح الواجهة وتجربة كل الأزرار والتحقق من الملفات.
2. إضافة تسجيل حساب/دخول حقيقي عبر خادم وقاعدة بيانات.
3. إضافة رفع الألعاب والصور إلى تخزين دائم، مع حالة مراجعة قبل النشر.
4. عرض الألعاب المنشورة للزوار وإتاحة تنزيلها.
5. تجهيز الموقع كتطبيق قابل للتثبيت (PWA)، ثم تحسينات إضافية.

لا تضع كلمات المرور أو مفاتيح الخدمات داخل ملفات الواجهة الأمامية.

## إضافات إدارة الصلاحيات (نسخة تجريبية محلية)
- الحسابات التي تسجّل أسماءها تظهر في لوحة الإدارة بعد أول تسجيل دخول.
- يمكن للمدير منح/سحب صلاحية رفع المحتوى للمستخدمين.
- قسم «الألعاب المشهورة» مخصص للمديرين فقط.
- المستخدم الذي لم يحصل على الموافقة لا يستطيع إضافة محتوى من واجهة الموقع.

**تنبيه مهم:** المشروع الحالي ما زال يستخدم IndexedDB وتسجيل دخول شكليًا داخل المتصفح. لذلك البيانات والصلاحيات محلية على نفس المتصفح، وليست قاعدة بيانات مشتركة، ولا تعتبر حماية حقيقية عند نشر الموقع على الإنترنت. كما أن أسماء المديرين الحالية (`Raft_99` و`Zeno`) معرفة في `app.js` ويمكن انتحالها بسبب غياب خادم تسجيل دخول. قبل الاستخدام العام يجب ربط المشروع بخادم وقاعدة بيانات ومصادقة حقيقية وقواعد صلاحيات على الخادم. لا ترفع هذه النسخة كما هي باعتبارها نظام أمان حقيقيًا.
